## 📖 简介

欢迎来到我的个人技术博客！这是一个**完全复刻 Windows 98 操作界面**的 SPA 应用，你将在一个怀旧的桌面环境中浏览技术文章、写笔记、画画、敲命令行、练打字，打两局游戏（飞机大战 / 桌面保卫战），还有一只 QQ 企鹅桌宠陪着你的任务栏。

博客内容聚焦 **Java 后端开发**，涵盖 Java 基础、Spring Boot、数据库、DevOps、前端等方向，记录了我从零开始学习编程的完整历程。

> 🔗 **在线体验**：`https://你的用户名.github.io`

## ✨ 特色功能

### 🖥️ Windows 98 桌面模拟

- **桌面图标** — 我的电脑、我的文档、控制面板、Internet 浏览器等经典图标，**可自由拖拽摆放**（localStorage 记住布局，「右键 → 排列图标」一键归位）
- **桌面右键菜单** — 排列图标 / 刷新 / 属性，属性打开「系统属性」对话框（版本/内容/浏览器/到访次数）
- **开始菜单** — 左下角经典的 Win98 开始按钮，带有动画弹出菜单，收录全部应用，侧边有 YF-Blog 竖排文字
- **任务栏** — 正在运行的窗口以任务栏按钮展示，支持点击切换激活
- **系统托盘** — 音量图标 + 单行时钟，悬停显示完整日期，**点击弹出 Win98 日历**（月份翻页、当日高亮）
- **屏幕保护程序** — 闲置 60 秒自动触发经典 **3D 管道屏保**，任意输入退出
- **关机画面** — 经典的 "It is now safe to turn off your computer" 关机界面

### 📝 技术博客

- **12+ 篇深度文章** — 从 Java Hello World 到 Spring Boot、Docker，每篇都是千字长文
- **5 大分类** — Java · Spring · Database · Frontend · DevOps
- **代码高亮** — 使用 Prism.js，支持 Java、Bash、SQL 语法高亮
- **Windows 资源管理器风格浏览** — 地址栏、文件图标、向上导航按钮
- **阅读体验** — 文章信息栏（日期/分类/字数/阅读时长）、上一篇/下一篇导航、切题自动回顶

### 🐧 桌宠 QQ 企鹅

- **经典形象**：按官方 QQ 企鹅 1:1 复刻——头身一体黑蛋、白色「8」字眼斑、大扁嘴、红围巾垂尾、黄嘴脚，纯 SVG 手绘，任意缩放不糊
- **自主行为**：沿任务栏上沿摇摇摆拍漫步、随机跳跃、眨眼、冒气泡说 QQ 年代的梗（「滴滴滴～」「您有一条新消息」）
- **悬浮模式**：拖到桌面任意高度松手就住下（不再乱走，只眨眼），**双击回家**回到任务栏；位置与模式 localStorage 记忆
- **打瞌睡**：90 秒无互动闭眼歪头冒「Zzz…」，点击唤醒
- **交互**：点击弹气泡 + 弹跳，拖拽拎起会晃腿，松手回弹
- **实现**：Vue 组件 + CSS 动画（零 Canvas），尊重 `prefers-reduced-motion`，移动端可拖

### 🛡️ 桌面保卫战（幸存者肉鸽）

- **主题**：你是桌面上的光标，病毒、蠕虫、弹窗、流氓软件从屏幕四周涌来，大眼夹精英蓄力突进
- **4 种武器**：环绕指针（轨道撞击）· 弹窗拦截（自动索敌弹）· 杀毒扫描（十字扫描线）· 磁盘整理（灼烧光环），各 5 级 + **进化形态**
- **5 种被动**：CPU 超频 / 内存优化 / 滚轮狂飙 / UPS 电源 / 磁盘磁铁
- **升级三选一**：拾取文档碎片升级，Win98 风格面板三选一构筑流派，支持 1/2/3 快捷键
- **波次推进**：敌人组合与密度按分钟推进，大眼夹精英定时降临，**5/10/15 分钟三场蓝屏死神 Boss 战**（环形错误弹幕 + 召唤病毒），击败最终 Boss 通关
- **掉落系统**：咖啡（回血）· 磁盘磁铁（全屏吸宝石）· 回收站（清空全场）
- **最佳纪录** localStorage 持久化
- **引擎**：delta-time + 精灵预渲染 + HiDPI，与飞机大战共享同一套模块化引擎模式（`src/game/survivor/`）

### 🎯 飞机大战游戏详情

- **4 种敌机类型**：侦察机 (1HP) · 战斗机 (6HP, 追踪弹) · 重装机 (9HP, 扇形弹) · 精英机 (14HP·1000分)
- **5 种移动模式**：下坠、正弦摇摆、水平折返、画圈盘旋、锯齿
- **V 字编队刷怪**：出生节奏每 4 拍随机刷出 4-8 架一队的俯冲编队，割草快感拉满
- **Boss 三阶段战**：血量 >50% 轨道旋转弹幕 → ≤50% 瞄准扇形 + 侧翼弹墙 → ≤25% 狂暴化（配色变红、移速/攻速提升、全向爆发），切换瞬间释放宣告弹环
- **4 种道具**：双倍火力 🔥 · 无敌护盾 🛡 · 速度提升 ⚡ · 回复生命 ❤
- **成长系统**：击杀累积提升子弹伤害 (最高 Lv5)、射速与移速，连杀 ≥5 触发额外分数加成
- **delta-time 引擎**：移动/计时全部按帧率换算，60Hz 与 144Hz 显示器上游戏速度一致
- **性能优化**：子弹、星云、行星、敌机全部预渲染为离屏精灵，菜单遮罩烘焙缓存
- **HiDPI 支持**：画布按 devicePixelRatio 渲染，Retina 屏幕画面锐利
- **移动端友好**：触摸拖动控制战机（自动上偏避免遮挡）、点击画面开始、窗口失焦自动暂停
- **无敌模式彩蛋**：按 `I` 键或点击按钮开启
- **最高分** localStorage 持久化存储

## 🚀 本地开发

### 环境要求

- [Node.js](https://nodejs.org/) >= 18
- npm >= 9

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/你的用户名/你的用户名.github.io.git
cd 你的用户名.github.io/vue-project

# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 📦 部署

### 自动部署（推荐）

项目已配置 GitHub Actions，推送代码到 `main` 分支自动触发构建部署：

1. **构建** → 安装 Node.js 20，`npm install` + `npm run build`
2. **部署** → 将 `vue-project/dist/` 推送到 `gh-pages` 分支
3. **上线** → GitHub Pages 自动更新，30 秒内生效

工作流文件：`.github/workflows/deploy.yml`

### 手动部署

```bash
cd vue-project
npm install && npm run build

# 使用 gh-pages 一键部署
npx gh-pages -d dist
```

> ⚠️ **注意**：如果部署到 `https://用户名.github.io/仓库名/` 而非根域名，需修改 `vite.config.ts` 中的 `base` 为 `'/仓库名/'`。

## 🎨 Windows 98 设计还原

本项目高度还原了 Windows 98 的经典视觉风格：

- **经典配色** — 银色 `#C0C0C0`、海军蓝 `#000080`、青色桌面 `#008080`
- **3D 立体边框** — 双层 `box-shadow` 模拟 Win98 凸起/凹陷效果，按钮按下时反转
- **像素级滚动条** — 纯 CSS 还原 Win95/98 风格滚动条，含箭头按钮 SVG
- **菜单栏** — 文件/编辑/查看/帮助下拉菜单，支持 `Alt+F/E/V/H` 键盘快捷键
- **窗口控件** — 最小化/最大化/关闭按钮，最大化时切换为还原图标（双矩形叠加）
- **系统菜单** — 点击窗口左上角图标弹出，含还原/移动/大小/最小化/最大化/关闭
- **响应式适配** — 桌面图标和窗口在移动端自动缩放，网格列数自适应
