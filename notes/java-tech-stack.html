Java 技术栈概览：从入门到实战

这篇文章汇总了 Java 常用的技术栈内容——覆盖语言基础、常用框架、数据库与持久化、构建与部署、测试与监控等模块。

快速实践建议： 从一个最小的 REST API 开始（Spring Boot + JPA + MySQL），为 2-3 个实体设计 CRUD；补上单元测试与简单日志；将经验沉淀为一篇复盘笔记。

1. 语言基础与核心库

  • Java 语法基础：变量、流程控制、面向对象（封装/继承/多态）。
  • 集合框架：List/Set/Map 及常见实现（ArrayList、HashSet、HashMap）。
  • 并发编程：线程、锁、并发工具（Executor、CompletableFuture）。
  • JVM 基础：类加载、内存模型、垃圾回收机制。

2. Spring & Spring Boot

  • 核心概念：IoC、AOP、依赖注入与切面。
  • Spring MVC：RESTful API 设计、全局异常处理。
  • Spring Boot：自动配置、Starter、配置管理。
  • 常用组件：Spring Data JPA、Spring Security。

3. 数据库与持久化

  • 关系型数据库：MySQL 基础、索引优化、事务与锁。
  • ORM 框架：JPA/Hibernate 映射、MyBatis-Plus。
  • NoSQL：Redis 常用数据结构、缓存策略。

4. 构建与部署

  • 构建工具：Maven（主流）或 Gradle。
  • 容器化：Docker 基础。
  • CI/CD：GitHub Actions 自动化构建。

5. 测试与质量

  • 单元测试：JUnit 5 + Mockito。
  • 集成测试：Spring Boot Test、Testcontainers。
  • 代码质量：SonarLint 静态扫描。

6. 学习路线建议

  1. Java SE 语法 + 集合 + 并发入门。
  2. Spring MVC 构建 REST API，配合数据库。
  3. 引入 Spring Boot，完善配置与组件，加入测试。
  4. 做一个小项目：例如 Todo/书签管理 API。
  5. 了解部署与监控，形成完整闭环。
